## 5. The relative cost of checking every job

From `runs/real-1-score.txt`: per delivered good job, arm A cost US$0.000242 and arm C cost US$0.000383. That is about 58% more (1.58 times; from the unrounded totals, US$0.075394 over 197 jobs against US$0.047824 over 198 jobs, 58.4%). ## 6. Limits the full design states that the report's cards now carry

- **A combined policy.** Arm D against arm E changes who does the work (3, 2, 2 and 1 jobs by rank) and whose work is checked (5 of 8) at the same time. It tests a combined routing policy, not checking intensity alone. Arm D against arm C also changes the work allocation. The check-only and work-only presets (DC, EC, DW, EW) exist in `config.json` and were not run.
- **Every job was tested in every arm.** The hidden tests were run on all 1,600 job-runs (1,600 `check` records). Partial checking limits only what the certifier is shown; the bench does not show savings from running fewer checks. Feedback and the routing ranks use outcomes from jobs that were not certified.
- **The missing-package jobs.** In arm A, 73 of the 80 missing-package jobs were false done, and 73 of the 116 false done in all (clean 21, ambiguous 22). Such a job's specification tells the agent to use a package that the grading sandbox lacks (job j31 names `fastcount`); the passing reference solution does not use it. A hidden-test pass is therefore not the same as doing exactly what the specification said. This is a construct-validity limit of the baseline false-done rate.
- **The Brier score is not calibration alone.** It also reflects task difficulty and how well forecasts separate passing from failing jobs, and the agents did unequal work in arms D and E.
- **Model settings.** Four models, reasoning off, temperature 0, seed 42, work replies capped at 1200 tokens, no tools. Results are about these models answering without thinking.
- **Privileged information.** The certifier was given the runner's own line from the hidden-test run, by design. It was not given missing, conflicting or misleading evidence. What it shows is gating on explicit test results. A deterministic program that read the same pass or fail line was not run as a control, so the bench does not show that a language-model reviewer adds anything over such a gate.
- **The inference unit.** Eight paired games (one per repetition) on one bank of 40 jobs and one pool of four models. Repetitions repeat the same jobs and models; they are not eight independent samples of agents or of tasks.

## 7. Statistics wording, and the paired differences

- The sign-flip test enumerates all 256 sign patterns for 8 pairs. That is exact for the null "the sign of each paired difference is a coin flip". It is not assumption-free: it needs the two arms' per-game differences to be symmetric around zero under no effect, and independence between games. Within a repetition the arms were not run in a randomised order. Treat the p values as a descriptive guide for this setup.
- **T1b** (good work delivered, D minus E, +0.0547, p = 0.2031) was a point-estimate safeguard against a loss of more than 0.05. It was not a non-inferiority test (no interval or one-sided test).
- **S1** (jobs pooled, McNemar, p = 0.6291) is descriptive. It treats dependent jobs as independent; the report does not use it as confirmatory evidence.
- **T2** compares Brier in rounds 4 and 5 with rounds 1 and 2. Without a no-feedback control it cannot say that feedback caused any change, and later rounds hold different jobs.
- The sealed scorer prints each test's mean and p, not the eight differences. It computes them (`diffs`). Here are the eight paired differences for each test, one per repetition in order 0 to 7, from the sealed `score.py` (no new analysis). No confidence interval is reported: the scorer does not compute one, and with 8 pairs an interval would be coarse.

## How to reproduce the figures in sections 2, 4 and 7

From this folder, with the sealed `score.py` (Python 3, standard library only):

```python
import json, sys
sys.path.insert(0, ".")
import score

recs = score.load_records("runs/real-1/room.jsonl")

for r in recs:
    if r["type"] in ("run_start", "run_end", "resume"):
        keep = {k: r[k] for k in ("seq", "ts", "type", "reps", "cap_usd", "stop_after_min", "spent_usd") if k in r}
        print("RECORD", json.dumps(keep))
reps_started = {}
for r in recs:
    if r["type"] == "game_start":
        reps_started.setdefault(r["rep"], r["ts"])
print("FIRST GAME OF EACH REP", json.dumps(reps_started, sort_keys=True))

checks = {(r["run"], r["job"]): r["passed"] for r in recs if r["type"] == "check"}
tally = {}
for r in recs:
    if r["type"] == "verdict" and r["run"].startswith("C|"):
        k = (r["verdict"], "hidden tests passed" if checks[(r["run"], r["job"])] else "hidden tests failed")
        tally[k] = tally.get(k, 0) + 1
for k in sorted(tally):
    print("ARM C VERDICT", k[0], "on a job whose", k[1], ":", tally[k])

res = score.score(recs)
for tid in ("T1", "T1b", "T2", "S2", "S3", "S4"):
    t = res["tests"][tid]
    d = [round(x, 5) for x in t["diffs"]]
    print("PAIRED %s (%s minus %s%s) mean %+.4f, p = %.4f; per-rep differences: %s; smallest %+.5f, largest %+.5f"
          % (tid, t.get("a", ""), t.get("b", ""), (", " + t["field"]) if "field" in t else "", t["mean"], t["p"],
             ", ".join("%+.5f" % x for x in d), min(d), max(d)))
```
