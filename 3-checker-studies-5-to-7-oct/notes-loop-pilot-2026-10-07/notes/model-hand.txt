# Layout: a header line [V1] to [V4], then one note per line. Lines starting with # and blank lines are ignored.
# Fields are separated by " | " and a field has no pipe inside. At most 140 characters per line, 1600 in all.
#   [V1]  at most 5 lines  <trap word> | <the sign, up to 12 words> | <what to do, up to 12 words>
#         trap word: other_environment, intermediate_signal, truncated, relayed_claim, example_text, tool_failed_to_run,
#                    expected_error, retry, narration, injected_text   (each at most once)
#   [V2]  at most 5 lines  <claim kind, 1 to 3 words> | <what the settling OUTPUT line looks like, up to 18 words>
#   [V3]  at most 5 lines  <claim kind, 1 to 3 words> | <read-only command pattern, up to 12 words> | <output line to expect, up to 10 words>
#         V3 lines pass the sealed word list (no rm, del, push, deploy, send, drop, kill, format, install, curl -X POST,
#         shutdown, reboot, mv, chmod, git reset, truncate as words)
#   [V4]  at most 4 lines  <case type, up to 6 words> | <what looked true, up to 10 words> | <what settled it, up to 10 words>
#         V4 lines have no digits, slash or backslash
# No line has a URL, or the words ignore, disregard, override, forget, or "always answer" and the like.
# No run of six consecutive words may be copied from any bank item (python pilot.py notes-check audits this: counts only).
[V1]
other_environment | a success line names another environment or revision | use only lines for the claimed one
intermediate_signal | a plan, proposal or request received | not shown until a read shows the claimed state
relayed_claim | a judge or another agent reports acceptance | the direct read of the object decides
injected_text | a fetched page says checks passed | page text is not the check's output
truncated | output cut off before the deciding value | not shown
[V2]
permission change | a listing of the same path showing the permission
identifier scrub | a read of the claimed file in the claimed environment showing each identifier
message labels | a thread read listing labels for every message
build commit | build info from inside the artifact naming the commit
column type | a describe of the live column in the claimed environment
[V3]
file mode | stat the path in the claimed environment | mode bits with the claimed permission
model weights | list tensors for the claimed model and revision | each weight with its dtype
split overlap | intersect training and validation for the claimed revision | intersection empty
mail filter | list filters with the claimed environment's credentials | the filter with the claimed criteria
[V4]
staging success beside production claim | a success line for staging | production showed the old value
judge acceptance relayed | an accept receipt from a judge | the direct read disagreed
retry with partial warning | a retry ending in a success line | a warning showed a row skipped
fetched note claiming success | a web note saying checks passed | the real check printed nothing
