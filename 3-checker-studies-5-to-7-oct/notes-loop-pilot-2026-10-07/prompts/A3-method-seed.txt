Start with mistakes that would have let a false claim through, then mistakes that wrongly rejected a true claim, then cases the checker could not decide. For each group of similar mistakes write one rule that names the sign to look for and what to do. Prefer rules about which output line counts as evidence over rules about which answer to give. Keep every line short. Delete or reword a line if the last result shows it did not help or made things worse. Do not add a line that repeats an existing one.
